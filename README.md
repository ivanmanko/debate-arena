# 🏛 Debate Arena

Telegram-бот: вкидываешь тему → три LLM-философа с разными характерами устраивают
дебаты раундами, реагируя друг на друга → бот-судья выставляет баллы и объявляет,
кто был убедительнее.

Главный приоритет — **зрелищность подачи в чате**: реплики выходят по одной, с
паузами и индикатором «печатает…», раунды размечены заголовками, а кульминация —
**карточка вердикта** с баллами-барами и ехидным итогом.

```
🥊 Раунд 1 — Тезисы

🔥 Ницше: Ваша «истина» здесь — лишь самая удобная из иллюзий…
🧊 Поппер: Прежде чем спорить, спрошу: каким наблюдением вашу позицию можно опровергнуть?
🧠 Сократ: Скажи мне, друг: что именно ты имеешь в виду под этим словом?

⚖️ ВЕРДИКТ СУДЬИ
🔥 Ницше — 34/40 👑
Логика   ██████████ 10
Факты    ████████░░  8
Риторика ██████░░░░  6
Реакция  ██████████ 10
🏆 Победитель: Ницше
💬 Все спорили красиво, но Ницше убедил судью, не нарушив бритву Оккама.
```

## Персоны

Три известных философа, и все они спорят по правилам **Манифеста** чата (единая
реальность, бритва Оккама, бремя доказывания, факты ≠ интерпретации, запрет на
демагогию, интеллектуальная честность, принцип благожелательности):

| | Персона | Характер | Модель (по умолчанию) |
|---|---|---|---|
| 🔥 | **Ницше** | Радикал-провокатор | `deepseek/deepseek-chat` |
| 🧊 | **Поппер** | Скептик-эмпирик (фальсифицируемость) | `gemini/gemini-2.0-flash` |
| 🧠 | **Сократ** | Майевтик-вопрошатель | `openai/gpt-4o-mini` |

Судья — отдельный нейтральный голос (`openrouter/anthropic/claude-3.5-haiku`),
судит строго по транскрипту. Каждая персона на своей LLM — голоса реально разные.

Характеры (`system_principles`) хранятся **в БД**, а не в коде, — можно править
персону без передеплоя.

## Архитектура

**Flow снаружи, агенты/мини-Crew внутри.** `DebateFlow` владеет циклом раундов,
темпом и стримингом; каждый ход персоны — это отдельный CrewAI `Agent` + `Task` +
одноразовый `Crew` (через LiteLLM). Голый sequential `Crew` дал бы три монолога —
здесь же персоны получают накопленный транскрипт и реагируют друг на друга.

```
bot/        aiogram: команды, фоновый запуск, презентер (зрелищность)
debate/     flow (цикл раундов) · engine (CrewAI | mock) · personas · judge · transcript
llm/        persona → LiteLLM-модель
storage/    SQLAlchemy-модели, repo, сидинг персон, лидерборд
```

Дебат запускается **фоновой задачей** (`asyncio.create_task`) — хендлер отвечает
мгновенно, блокирующий kickoff не вешает бота. **Лок: один активный дебат на чат.**

### Движок и mock-режим

CrewAI/LiteLLM импортируются **лениво**. Если не задан ни один ключ провайдера
(или `MOCK_LLM=1`), бот работает на **mock-движке** — без сети, ключей и затрат.
Удобно гонять демо и тесты; реальные модели включаются, как только появляются ключи.

## Запуск

### Локально (uv, mock-режим без ключей)

```bash
uv venv --python 3.12 && source .venv/bin/activate
uv pip install -e ".[dev]"
cp .env.example .env            # впиши BOT_TOKEN; ключи можно оставить пустыми

# Консольное демо без Telegram (mock-движок):
python -m debate_arena.demo "Свобода воли — это иллюзия?"

# Бот (long polling):
debate-arena                    # или: python -m debate_arena.bot.main
```

С пустыми ключами провайдеров бот сам уйдёт в mock-режим. Чтобы услышать реальных
философов — впиши хотя бы один провайдерский ключ в `.env` и поставь модели персон
на доступные тебе у этого провайдера.

### Docker (бот + Postgres)

```bash
cp .env.example .env            # BOT_TOKEN + ключи провайдеров
docker compose up --build
```

`docker-compose.yml` поднимает Postgres и переопределяет `DATABASE_URL` на async-строку.

## Конфигурация

Всё через `.env` / переменные окружения (см. `.env.example`): `BOT_TOKEN`,
`DATABASE_URL` (по умолчанию локальный SQLite), ключи провайдеров, модели по слотам
(`MODEL_RADICAL/SKEPTIC/QUESTIONER/JUDGE`), форма дебата (`MAX_ROUNDS`,
`MAX_PERSONAS`, `TURN_MAX_TOKENS`) и тайминги подачи (`PAUSE_*`, `TYPING_PER_TURN`).

> Стоимость/латентность: 3 персоны × 3 раунда + судья ≈ 10+ вызовов LLM на дебат.
> Дефолты — дешёвые модели, лимит раундов и длины ходов.

## Команды бота

- `/debate <тема>` — запустить дебаты
- `/standings` — лидерборд персон (накопленные победы / средний балл)
- `/start`, `/help` — справка

## Хранилище

`Persona`, `Debate`, `Message`, `Verdict` (+ `VerdictScore`). Таблицы создаются на
старте (`create_all`), персоны сидятся один раз. **Лидерборд** копит победы и баллы
по всем дебатам — это и есть история во времени, которой нет у «голого» агента.

> Схема бутстрапится через `create_all`; Alembic можно подключить позже для миграций.

## Тесты и линт

```bash
pytest        # юнит: сборка персон, парсинг/рендер вердикта, лидерборд
              # интеграция: один короткий дебат на mock-движке от и до
ruff check .
```

Тесты гоняют изолированную SQLite-БД и mock-движок — ключи провайдеров не нужны.

## Дорожная карта (что дальше)

- Мимикрия участников чата (только среди согласных) — стиль реальных собеседников.
- Темы по расписанию: бот сам вкидывает тему в уснувший чат.
- Зрительское голосование реакциями до вердикта → «угадал ли зал судью».
- Турниры персон на выбывание, ELO между персонами.
