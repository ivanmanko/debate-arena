# ⚖️ Rational Check — проверка здравого смысла

Вставляешь текст — три **рациональных аналитика** (LLM-агенты без философских школ,
апологеты рационального мышления по Манифесту здравого смысла) разбирают его независимо,
потом перекрёстно проверяют друг друга: критикуют слабые места и явно принимают
рациональные доводы коллег. **Судья** выносит структурированный вердикт: что самое
рациональное, что доказано / вероятно / непроверяемо, какие уловки найдены, что
опровергло бы вывод и что из этого следует.

Интерфейсы: **веб** (основной), Telegram-бот, консоль. Провайдеры: **Anthropic**
(по умолчанию) и **DeepSeek**; без ключей — mock-режим.

```
Раунд 1 · Независимый разбор      🔎 Эмпирик · 🧩 Логик · ⚖️ Стилмен — параллельно, не видя друг друга
Раунд 2 · Перекрёстная проверка   Принимаю: … / Оспариваю: … / Уточняю: …
⚖️ Вердикт судьи                  рациональность текста 0–100, утверждения со статусами,
                                   уловки, сильнейшая версия, критерий опровержения, so what
```

## Запуск

### Локально (uv)

```bash
uv sync
cp .env.example .env            # впиши ANTHROPIC_API_KEY (или DEEPSEEK_API_KEY)
uv run rational-check           # http://127.0.0.1:8000
```

Без ключей приложение стартует в **mock-режиме** (заглушки вместо моделей) и говорит об
этом в интерфейсе — удобно посмотреть UI, ничего не тратя.

Другие интерфейсы:

```bash
uv run python -m debate_arena.interface.cli "текст для разбора" --rounds 2
uv run rational-check-bot        # нужен BOT_TOKEN; /check <текст> в чате
```

### Docker (web + Postgres, бот по профилю)

```bash
cp .env.example .env
docker compose up -d --build                  # http://localhost:8000
docker compose --profile bot up -d            # плюс Telegram-бот
```

## Конфигурация

Всё через `.env` (см. `.env.example`). Главное:

| Переменная | Назначение | По умолчанию |
|---|---|---|
| `ANTHROPIC_API_KEY` / `DEEPSEEK_API_KEY` | ключи провайдеров | — |
| `MODEL_ANALYST`, `MODEL_JUDGE` | `provider/model` | `anthropic/claude-opus-5-5` |
| `ANALYST_EFFORT`, `JUDGE_EFFORT` | глубина размышления Anthropic | `medium`, `high` |
| `DEFAULT_ROUNDS`, `MAX_ROUNDS` | раунды | 2, 3 |
| `MAX_TEXT_CHARS` | лимит текста | 20 000 |
| `LANGUAGE` | язык реплик и вердикта | русский |
| `DATABASE_URL` | SQLAlchemy async URL | локальный SQLite |
| `PUBLIC_URL` | адрес веба для ссылок из бота | — |

Полный список констант поведения с обоснованием — `SPEC.md` §7.

> Стоимость: разбор = `3 × раундов + 1` вызовов модели (7 при двух раундах). На Opus 5.5
> thinking входит в лимит токенов; бюджеты реплик — `TURN_MAX_TOKENS` / `JUDGE_MAX_TOKENS`.

## Что на фронте

- Форма: текст, необязательный вопрос «что именно проверить», глубина (1–3 раунда),
  выбор модели из доступных по ключам, счётчик символов, ⌘/Ctrl+Enter.
- Живой ход по SSE: чипы аналитиков со статусом «думает / готово», раунды, карточки
  реплик с размеченными блоками **Принимаю / Оспариваю / Уточняю**, таймер.
- Вердикт: шкала рациональности текста, заключение и уверенность судьи, колонки
  «установлено / вероятно / неопределённо», таблица утверждений со статусами, уловки с
  цитатами, сильнейшая версия · что изменит вердикт · что из этого следует, оценки
  аналитиков с коронкой за самую рациональную линию.
- История разборов в боковой панели, удаление, ссылка на разбор, копирование в
  Markdown, скачивание JSON, «разобрать снова», тёмная тема, мобильная вёрстка.

(SSE) · `GET /api/analyses` · `DELETE /api/analyses/{id}` · `GET /api/config` ·
`GET /health`. Контракт — `SPEC.md` §3, схемы — `interface/api/schemas.py`.

## Cut scope

- **Потоковые токены внутри реплики** — SSE отдаёт реплику целиком; на Opus 5.5 с
  thinking реплика идёт 20–60 с, индикатор «думает…» это покрывает. Чтобы добавить:
  `messages.stream` в `AnthropicProvider` + событие `delta`.
- **Серверный fallback при отказе модели** (beta `server-side-fallback`) не включён:
  отказ показывается как ошибка разбора. Включить — флаг в `AnthropicProvider`.
- **Веб-поиск / проверка по источникам** — аналитики работают только с текстом и обязаны
  писать «не могу проверить». Нужен tool use у провайдера.
- **Аутентификация и квоты** — инструмент личный.
- **Eval качества промптов** — линзы и Манифест не измерены на golden set (ADR-002,
  Revisit when).
- **Alembic** — схема создаётся `create_all`; миграции подключить при первом изменении схемы.
