# ADR-002: Три аналитика с общим Манифестом и разными методологическими линзами; слепой первый раунд; судья со структурированным вердиктом

- **Status:** Accepted
- **Date:** 2026-10-11

## Context

Требование: участники — «суперумные и рациональные все, не относящиеся ни к каким
философским течениям, апологеты рационального мышления»; критичны друг к другу, но
принимают рациональные ответы; судья решает, что самое рациональное. Первая версия имела
трёх философов-персонажей с характерами и лидерборд.

## Decision

1. Аналитики описаны **в коде** (`domain/analysts.py`), не в БД: три спеки с одинаковым
   системным Манифестом (7 столпов из скилла common-sense) и разной **линзой** — не школой:
   - 🔎 **Эмпирик** — факты, источники, бремя доказывания, проверяемость;
   - 🧩 **Логик** — структура аргумента, валидность, скрытые посылки, софизмы;
   - ⚖️ **Стилмен** — сильнейшая версия тезиса, альтернативные объяснения, Оккам,
     границы применимости.
   Линзы нужны, чтобы три вызова одной модели не дали три одинаковых ответа; при этом все
   трое подчинены одним правилам и одной цели — найти самое рациональное, а не победить.
2. **Раунд 1 слепой и параллельный**: аналитик не видит коллег — исключает якорение на
   первом ответе. Раунды 2+ последовательные с полным транскриптом и обязательными блоками
   «Принимаю / Оспариваю / Уточняю» (SPEC §4).
3. **Судья** — отдельный системный промпт, structured output по схеме `Verdict` (SPEC
   §3.3): заключение, rationality_score текста, статусы утверждений, софизмы, стилмен,
   критерий опровержения, so-what, оценки аналитиков.
4. Лидерборд и персоны в БД удалены: ценность истории — в самих разборах, а не в
   «победах» одинаковых агентов.

## Alternatives considered

1. **Три полностью идентичных агента.** Чище по букве требования; rejected: одна модель с
   одним промптом даёт почти одинаковые реплики — перекрёстная проверка вырождается.
2. **Оставить философов, но «рационализировать» промпты.** rejected: пользователь явно
   просит без течений; имена Ницше/Поппера сами по себе задают школу.
3. **Все раунды параллельные.** Быстрее; rejected: в перекрёстном раунде ценность — в
   реакции на уже сказанное в этом же раунде.
4. **Аналитики в БД (как было).** Редактирование без деплоя; rejected: промпты — часть
   поведения и должны быть в git рядом со SPEC; UI для их правки не в scope.

## Consequences

- Разбор = `3×rounds + 1` вызовов; при 2 раундах и Opus 5.5 — семь вызовов.
- Эффект линз не измерен; потребуется eval на наборе текстов (см. Revisit).

### Revision: соревнование → совместный поиск истины; режим диалога (2026-10-11)

**Было:** судья оценивал каждого аналитика (rigor/evidence/charity/responsiveness) и
называл `most_rational`; UI рисовал коронку.
**Что показал прогон/обсуждение:** пользователь явно сформулировал цель — истина, а не
победитель; баллы аналитикам возвращали соревновательную рамку, которой в задаче нет.
**Стало:** п. 3 — судья формулирует то, что ближе всего к истине, фиксирует консенсус и
открытые вопросы аналитиков; оценки аналитиков удалены из схемы и UI. Добавлен режим
**диалога** (SPEC §4.0): собеседники распознаются парсером, судья оценивает близость
каждого к истине (`truth_proximity`, `right_about`, `wrong_about`) и называет
`closest_to_truth`. Правило: «ближе к истине» — это чья *картина* точнее, не кто
убедительнее; у каждого участника обязательно названо, что у него верно.
**Отклонено:** балл «качество дискуссии» за собеседника (риторика, манера) — это снова
соревнование; оставлена только близость к истине.

### Revision: рамка Манифеста — сторона спора, а не нейтральная точка (2026-10-11)

**Было:** аналитикам говорилось «ты не принадлежишь ни к какой философской школе… твой
единственный метод — Манифест»; п. 3 Манифеста обнулял любой тезис без доказательств.
**Что показал прогон/обсуждение:** разбор диалога о здравом смысле — его прочитала другая
модель (Opus) и указала, что собеседник, оспаривавший сами основания Манифеста
(«фальсифицируемость — тоже конвенция», «наука строит модели»), проиграл отчасти по
определению: судья оценивал тезис по правилам, которые тот оспаривал. Источники крена в
промптах: попперовский критерий как аксиома (п. 6), реализм в определении истины (п. 1),
«умножить на ноль» для тезисов, которые опытом не доказываются по природе (п. 3), и
ложное заявление о нейтральности, из-за которого модель не замечает, что сама — сторона.
**Стало:** (1) блок «Границы рамки» (`FRAME_NOTE`) у всех ролей: Манифест — позиция
(критический рационализм, научный реализм); если материал оспаривает её основания —
сказать это, не засчитывать рамке победу по определению, оценивать по согласованности и
силе аргументов; заявление о нейтральности убрано. (2) П. 3 обнуляет только утверждения
о фактах; ценностные, нормативные, определительные и эпистемологические — проверяются на
согласованность и следствия. (3) Шаг протокола «тип разногласия»: о фактах / о целях и
нормах / о словах (SPEC §4.1). (4) Eval `evals/frame_bias`: четыре диалога, где одна
сторона оспаривает рамку, в двух порядках реплик; меряет разрыв `truth_proximity`
защитника и оппонента рамки и эффект порядка.
**Отклонено:** убрать Манифест для философских тем (инструмент — проверка по Манифесту,
на обычных текстах крен к проверяемости нужен); отдельный флаг `frame_challenged` в
`Verdict` (меняет контракт API ради того, что судья может сказать в `narrative`).
**Цена:** п. 3 в промпте теперь расходится с первоисточником — скиллом `common-sense`.

## Revisit when

- Eval покажет, что линзы дают < 2 различающихся позиций в раунде 1 на golden set.
- `evals/frame_bias` после ревизии всё ещё показывает разрыв в пользу защитника рамки,
  сопоставимый с исходным, — тогда блок «Границы рамки» не работает и нужна другая мера.
- Понадобится ролевая настройка аналитиков пользователем — тогда вернуть хранение в БД.
